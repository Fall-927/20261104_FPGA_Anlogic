# 第一版 SD 图片文件规则

当前第一版读取器采用固定连续扇区模式，尚未加入 FAT16/FAT32 目录解析。

- SD 卡建立一个 FAT32 主分区。
- `IMAGE.BMP` 必须复制后保持连续存储，起始扇区需由 PC 工具查出。
- 将起始扇区填写到 `sd_bmp_fixed_lba_reader.v` 的 `IMAGE_LBA` 参数。
- 读取长度固定为 1801 个 512 字节扇区，覆盖 921600 字节像素和 54 字节文件头。
- 图片格式：640x480、24-bit、BI_RGB、无压缩、标准 54 字节像素偏移。

这是第一版硬件打通方案，不是最终 FAT 文件系统方案。若文件被删除重写，起始扇区可能改变，必须重新查询。

只支持 SD v2 SDHC/SDXC，不支持 SDSC。默认 LBA=2048 只是示例，
通常并不是 FAT32 文件起始位置。输入 BMP 必须是正高度 bottom-up，
BITMAPINFOHEADER 长度 40。像素在缓存中转成 RGB565，存在色深损失。
FPGA 不依赖文件名；IMAGE.BMP 是 PC 定位工具约定的根目录短文件名。
