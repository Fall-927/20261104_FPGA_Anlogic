## 按键

统一扫描矩阵第4行（key_row[3]，管脚 D9），低电平有效。
原文档写 KEY12/13/14，但原代码实际 row==3。以行列为准，
按板参考映射是 KEY0/1/2/3；若面板印字不同按以下电气位置确认。

| 列 / 列管脚 | 照片模式 | 视频模式 |
| --- | --- | --- |
| col0 / E11（KEY0） | 上一张，三张循环 | 无操作 |
| col1 / D11（KEY1） | 下一张，三张循环 | 无操作 |
| col2 / C11（KEY2） | 自动 / 手动切换 | 暂停 / 继续 |
| col3 / F10（KEY3） | 切换到视频 | 切换到照片 |

上电默认照片手动模式，自动间隔300个60Hz帧，约5秒。
消抖约84ms，长按只触发一次；暂停在视频素材帧边界生效。
切模式保留照片索引、自动/手动状态及视频暂停状态。
切回视频重新从片头装载，不是断点续播；切回照片重新读取三张照片，
装载期间黑屏静音，HDMI时序保持运行。模式键在加载或错误状态仍可用。
照片静音；视频使用原声。保持原工程的瞬时欠载容错策略。

## 构建

检查本轮报告和全部告警后，执行 source generate_media_bit.tcl。
最终文件名 HDMI_MEDIA.bit，不要误用 HDMI_VIDEO.bit / HDMI_SLIDESHOW.bit。
不自动烧写开发板。
