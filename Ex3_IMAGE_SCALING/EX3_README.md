# Ex3 图片分辨率读取与缩放（基于v2.0）

本目录从发布提交a89b92e建立；不包含Ex5波形，不改远端main和v2.0。
工程入口HDMI_MEDIA.al，source build_media.tcl，检查本轮时序后执行
source generate_media_bit.tcl。输出HDMI_MEDIA.bit，仅用于本次已核实SD卡。

## 实现

- bmp_scale_stream解析BMP实际宽高、像素偏移、文件长度、行补齐。
- 支持1..1280宽、1..1024高、正高度、DIB40、24bit BI_RGB、偏移54..4096。
  缩放后至少1像素；极端长宽比导致目标为0时拒绝。拒绝压缩/负高度/32bit。
- FPGA逐行缓存源像素，整数DDA最近邻，按比例居中补黑边；不要求电脑预缩放。
- 输出固定640×480 bottom-up RGB565，复用原三帧SDRAM显示缓冲和翻行显示逻辑。
- 恢复式除法器仅在文件头解析时算比例，不使用组合大除法；行RAM同步读取推断BRAM。
- SD和像素输出均有背压，装载完三张后再显示；原手动/自动、暂停、模式切换保留。
- 当前为最近邻，不是双线性；放大有块状边缘，大幅缩小可能混叠。后续再提升质量。
