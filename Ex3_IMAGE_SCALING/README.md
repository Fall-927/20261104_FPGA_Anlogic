# 图片 / 视频基础播放 + Ex3 图片缩放

仓库目录：Ex3_IMAGE_SCALING。基于v2.0基础播放接入用户反馈可正常播放的Ex3，
没有Ex1字幕、Ex2转场、Ex4 OSD、Ex5音频可视化等其他扩展。
图片缩放就是本次要求保留的Ex3功能，不额外增加其他功能或按键。

## 功能

- 图片：六张手动切换、约5秒自动轮播（原三张+三张缩放图）。
- Ex3：不同尺寸24bit BMP由FPGA读取并最近邻等比例缩放，居中补黑边。
- 视频：AV10 v2视频与双声道原声，暂停/继续、循环播放。
- 照片/视频按键切换；返回照片重新装载，返回视频从片头开始。

矩阵第4行col0/1/2/3分别为上一张、下一张、自动/手动或暂停/继续、切换照片/视频。
参考板映射KEY0/1/2/3，以实际行列为准。

## 使用

打开HDMI_MEDIA.al，顶层hdmi_media_top，目标EG4S20BG256，TD4.6。
本轮将已通过播放验证的三张Ex3版本扩展为六张，修改了照片索引、装载和缓存范围。
需重新构建六张版bit，六张版尚待实板回归。源码仓库不附带bit和构建产物。
