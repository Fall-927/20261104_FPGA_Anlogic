# 颜穆糖广场 FPGA 离线广告屏

基于安路 **EG4S20BG256** 的 SD 卡离线多媒体展示系统。运行期由 FPGA 完成图片缓存、节目排播、通知仲裁及 HDMI 音视频输出，不依赖上位机、网络或外接处理器。

当前版本：[v3.0 最终版](https://github.com/Fall-927/20261104_FPGA_Anlogic/releases/tag/v3.0)。工程入口：[EG4S20_CORE/HDMI_MEDIA.al](EG4S20_CORE/HDMI_MEDIA.al)，顶层 `hdmi_media_top`，工具为安路 TD 4.6。

## 展示功能

- 八图手动翻页与分组排播；基础周期5/10/15/30秒，第2、5张重点广告加倍停留，配合淡出淡入。
- 信息496×372、活动480×288、全屏640×480三套版式，等比例缩放；HDMI输出始终为640×480。
- 中文品牌界面、滚动字幕、亮度/对比度调节及PCM时域幅度柱条（不是FFT频谱）。
- 图片背景音乐、五类通知语音、音量及全局静音。通知替换音乐，不执行混音。
- 拨码通知与优先级仲裁；60/180/300/600秒倒计时，到时插播20秒活动通知。
- AV10 v2原声视频：320×240、10帧/秒，显示480×360；不直接解码MP4。
- 可检测的读卡或素材解析故障显示内置中文兜底页。

## 快速启动

1. 使用对应核心板、多媒体底板、供电、SD卡和支持音频的HDMI显示设备。声音由HDMI输出。
2. 插入与固件匹配的原SD卡，按原下载流程烧录 `EG4S20_CORE/HDMI_MEDIA.bit`。它是FPGA配置文件，不是Windows程序。
3. 关闭逻辑SW0～SW3、SW5，开启SW4音乐和SW6自动排播，等待八图预载完成。

操作及介质说明见 [使用说明](docs/使用说明.md)。物理拨码编号、ON方向及键盘朝向需按电气接线核对。

**本仓库及发布包不含图片、音乐、视频和音频包。** 固件按绝对SD扇区地址读取，不按文件名搜索。新卡或重新复制素材后，须核验连续性与地址，更新顶层参数和音频目录后重新构建。

## 工程与构建

`EG4S20_CORE/rtl` 为播放、排播、UI、SD/BMP、SDRAM及HDMI逻辑；`al_ip` 为必需厂商IP；`constraints` 为引脚和时钟约束。目录内另有工程入口、构建脚本、当前位流及第三方声明。

TD控制台进入 `EG4S20_CORE` 后执行：

```tcl
source build_media.tcl
# 检查本轮静态时序结果后再生成位流
source generate_media_bit.tcl
```

核心包不保留布局布线数据库、日志、素材转换工具和仿真环境，必须完整构建后再生成位流。普通注释已精简，第三方版权及必要综合指令保留。旧版可从历史提交与Releases获取。

## 验证边界与限制

既有完整工程记录为setup/hold均0错误，最小裕量分别1.264ns/0.104ns。精简版TD elaboration通过，附带位流与整理前一致；本次发布整理未重新完成全流程布局布线或实板验收。额外RTL检查仍报告 `player.fb[0]` 未驱动，与精简前基线一致，不宣称全部检查无告警。

切换版式重载图片；视频触发通知会退出视频并加载图片/语音，有加载延迟。恢复音乐或视频从头开始，不做断点续播。运行计时不是实时时钟；未实现远程控制、天气或传感器采集。掉电、失钟及HDMI物理故障不属于兜底保证范围。
