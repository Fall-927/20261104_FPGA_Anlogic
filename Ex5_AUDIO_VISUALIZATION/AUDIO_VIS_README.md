# 2.0基础上的音频波形叠加

基于已发布的2.0融合工程新增，不改照片/视频按键语义、SD卡格式和地址。
这是时域波形包络，不是FFT频谱，不标注频率轴。

## 显示

- 视频有效播放时，在640×480画面底部x=64..575、y=368..463显示512×96面板。
- 背景为原视频RGB的1/4亮度，保留边框、网格和中心线；绿色波形、黄色暂停波形。
- 左右声道都参与每个时间桶的最小/最大值，避免L/R反相相加抵消。
- 每桶8组48kHz样本、128桶，一页1024组样本，覆盖21.333ms；每桶横向4像素。
- PCM取高6位有符号幅度（-32..31），中心y=416，轨迹最大y=385..448。
- 采集使用HDMI实际sample_tick和pcm_left/right，不重新读取音频，不对音频施加背压。
- 双缓冲，仅垂直消隐发布完整页面；等下一消隐时会跳过采集，不是连续长时录音。
- 暂停保留当前波形；切模式/重新装载清空有效状态；照片模式完全旁路。
- 静音显示中心线。沿用原PCM欠载行为；本功能不额外修复原音频欠载策略。

## 文件与启用

rtl/audio_wave_overlay.v实现采集与像素叠加。
hdmi_media_top.v参数AUDIO_VIS默认1，可设0编译关闭。
hdmi_video_top.v默认AUDIO_VIS=0，保留独立视频工程原行为。
HDMI_MEDIA.al已加入新模块，构建仍使用build_media.tcl / generate_media_bit.tcl。
SD文件不需要重新转换，移动或替换后仍需重新定位LBA。
