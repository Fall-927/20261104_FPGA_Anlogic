# v3.0 使用说明

## 拨码与优先级

逻辑高有效，约20ms消抖；物理编号和方向以接线为准。

| 开关 | 功能 | 管脚 |
|---|---|---|
| SW0 | 温馨提示画面与语音 | A9 |
| SW1 | 寻人演示画面与语音 | A10 |
| SW2 | 消防演示画面与语音 | B10 |
| SW3 | 闭店提醒画面与语音 | A11 |
| SW4 | 图片背景音乐 | A12 |
| SW5 | 全局静音 | B12 |
| SW6 | 图片自动排播 | A13 |
| SW7 | 保留 | A14 |

优先级：消防 > 寻人 > 闭店 > 温馨提示 > 活动插播 > 广告。高优先级通知覆盖时暂停倒计时及活动插播，解除后恢复仍有效的低优先级通知。语音循环并替换音乐，不混音。

## 矩阵按键

下表为电气行列0～3，不是键帽数字。

| 行 | 列0 | 列1 | 列2 | 列3 |
|---|---|---|---|---|
| 0 | 亮度/对比度恢复8 | 信息→活动→全屏 | 周期5→10→15→30秒 | 幅度条开关 |
| 1 | 对比度减 | 对比度加 | 全部→1～3→4～6→7～8组 | 倒计时启动/取消 |
| 2 | 亮度减 | 亮度加 | 空闲选择倒计时时长 | 音量16→15…0→16 |
| 3 | 上一张 | 下一张 | 视频暂停/继续 | 图片/视频切换 |

亮度、对比度、音量范围0～16；前两项默认8，音量默认16。通知期间冻结图片排播和翻页，切换版式需要重载素材。

## SD卡配置

运行期不解析FAT目录，按512字节绝对扇区读取，要求文件连续存储。以下地址只对应当前核验卡，不适用于任意新卡。

| 参数 | 文件名 | 绝对LBA |
|---|---|---|
| IMAGE0_LBA | IMAGE0.BMP | 246112 |
| IMAGE1_LBA | IMAGE1.BMP | 247968 |
| IMAGE2_LBA | IMAGE2.BMP | 249824 |
| IMAGE3_LBA | S800600.BMP | 251680 |
| IMAGE4_LBA | S1280720.BMP | 253536 |
| IMAGE5_LBA | S480800.BMP | 255392 |
| IMAGE6_LBA | S320240.BMP | 257248 |
| IMAGE7_LBA | S641481.BMP | 259104 |
| VIDEO_LBA | VIDEO0.AV | 264608 |
| AUDIO_BASE_LBA | AUDIO.PAK | 312352 |

现有八图统一640×480、24位非压缩BMP，每张921654字节。历史文件名中的尺寸不代表实际尺寸。解析器支持正高度、40字节信息头、偏移54～4096、宽1～1280、高1～1024，长度须符合行对齐规则。

音频为48kHz双声道16位小端PCM，轨道512字节对齐；六轨顺序为背景音乐、温馨提示、寻人、消防、闭店、活动。偏移与扇区长度由 `rtl/audio_catalog.vh` 指定，新包须同步更新目录。当前包135056384字节，SHA256：`fc251c2c8ff33172eaa6d5d3d6ae857ea00ae1b924566d6fe5c601567bb6a810`。

视频为AV10 v2：512字节头，每包153600字节RGB565画面、19200字节PCM及256字节填充。格式细节见 `av15_unpack.v`，不能将MP4改扩展名使用。核心包未附素材制作工具。

换卡、替换或移动文件前先备份，之后重新核验连续性、绝对LBA与音频目录，更新 `rtl/hdmi_media_top.v` 并重新构建。`MEDIA_LBA_VERIFIED=1` 只记录当前卡已核验，不会自动定位新卡。

## 故障检查

| 现象 | 检查 |
|---|---|
| HDMI无信号 | 供电、输入源、下载结果、工程顶层 |
| 有UI无图片 | 等待预载、SD接触、LBA、连续性及BMP格式 |
| 有图片无音乐 | SW4、SW5、音量、显示器音频、音频包与目录 |
| 一直显示通知 | SW0～3逻辑状态与优先级 |
| 视频未出现 | 行3列3切换；图片排播不会自动切入视频 |
| 切版式暂时加载 | 重读八图属于当前实现行为 |

无可读SD卡时不能播放卡上语音；兜底不能保障掉电、失钟或HDMI物理故障。应急相关功能仅用于演示。
