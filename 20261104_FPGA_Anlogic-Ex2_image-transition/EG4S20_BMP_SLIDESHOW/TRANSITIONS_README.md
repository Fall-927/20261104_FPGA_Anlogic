# 拓展任务 2：图片轮播与淡出淡入转场

基于现有 HDMI 音频工程直接改写，不改变 SD 图片地址、SDRAM 布局、HDMI 时序、管脚或音频播放条件。
本仓库仅包含当前转场版本；基础版本的本机备份不属于仓库依赖。

## 操作

- KEY12：上一张；KEY13：下一张；KEY14：自动/手动切换。默认仍为手动。
- 自动模式每张完整亮度保持约 5 秒，再进行约 1.1 秒的转场。
- 过程为旧图 32 级淡出 → 黑场切换帧基址 → 新图 32 级淡入。
- 转场中继续按键会更新待显示目标；当前转场完成后再处理最新目标，不在半途突变。
- HDMI 同步、像素读取和测试音在转场中持续工作，黑场只改变图像亮度，不关闭视频或音频链路。

这是 fade-through-black（经黑场淡出淡入），不是两张图片同时叠加的交叉溶解，也不包含滑动效果。
复用原单路 SDRAM 读取，未增加帧缓存或双图读取带宽。

## 代码与参数

`rtl/slideshow_controls.v` 增加转场状态机；`rtl/slideshow_fade.v` 对 RGB888 分量乘以 0～32 的增益，除以 32。
满亮度逐位保持原 RGB565 扩展值，零亮度为纯黑，无额外像素流水延迟。
亮度及图片选择只在垂直消隐边界改变，图片基址仅在零亮度时改变。

`AUTO_FRAMES=300`：完整亮度停留帧数；`FADE_STEP_FRAMES=1`：每级渐变持续帧数。
默认每方向 32 帧，总转场约 66 帧。参数应设为正整数。
这些参数在 `slideshow_controls` 定义或顶层实例参数中调整。
